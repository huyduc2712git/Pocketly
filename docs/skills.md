# Discovered and Configured Skills

## 1. UI/UX Pro Max Ecosystem
Installed via `npx -y ui-ux-pro-max-cli init -a antigravity` to `.agents/skills/`:
- **`ui-ux-pro-max`**: Design intelligence engine for fintech product design, visual style, color palette, typography, dashboard patterns, accessibility, micro-animations, and anti-pattern prevention.
- **`design-system`**: Design system tokens generation, responsive grids, dark mode color science, spacing tokens, and component contracts.
- **`design`**: User experience design principles, layout hierarchy, interaction design, touch target compliance (min 48x48dp), and contrast ratio (WCAG AAA/AA).
- **`brand`**: Fintech branding, trust cues, color psychology (calm navy/slate/emerald, zero excessive neon/noise).
- **`ui-styling`**: CSS/Flutter styling tokens, typography pairings, surface elevations, and glassmorphism / card containers.
- **`banner-design`**: Smart Insight notification banners and promotional widgets.

## 2. Built-in Antigravity Skills
- **`agy-customizations`**: Customization system for rules, skills, plugins, and MCP servers.
- **`antigravity-guide`**: Complete guide and reference for Google Antigravity.
